# Auto-crop Implementation Plan

> Execute inline in this approved task. Automated tests are deferred at the user's request; compile and manually exercise the workflow.

**Goal:** Detect a document quadrilateral, let users adjust it, and save a perspective-corrected preview.
**Architecture:** The existing Worker invokes an isolated OpenCV Python process on the normalized, orientation-corrected source preview. Revisioned crop jobs publish assets only when their revision is still current. Angular draws an SVG overlay over that same source.
**Tech stack:** Angular, EF Core/PostgreSQL, private R2, Magick.NET, OpenCV Python subprocess with a 30-second deadline.
**Spec:** ../specs/2026-09-12-auto-crop-perspective-design.md

## Constraints
- JPEG and PNG editing initially; preserve immutable originals and previous usable previews.
- Four normalized points in TL, TR, BR, BL order, convex, finite, within [0,1], at least 1% image area.
- Source preview at most 2000px; OpenCV input at most 25MB/4MP; output at most 2000px/12MB.
- Owner checks on every API, optimistic revisions, transactionally queued jobs, no automated tests in this task.

## 1. Domain and persistence
- [ ] Add CropPoint/CropGeometry validation in Domain/Documents/CropGeometry.cs.
- [ ] Extend Page with source key, corners JSON, confidence, source, revision, applied revision and crop status.
- [ ] Add EF migration/snapshot and matching idempotent local SQL for existing accepted JPEG/PNG pages.

## 2. Worker crop jobs
- [ ] Add processing/crop_image.py: detect using Gaussian blur/Canny/contours/convex quadrilaterals; confidence fallback to full bounds; warp with getPerspectiveTransform/warpPerspective.
- [ ] Add CropProcessor.RunAsync(Guid pageId, int revision, bool detect, CancellationToken). Download the fixed source, enforce limits, invoke Python with an argument list, kill on timeout, upload revisioned results, conditionally publish on matching revision.
- [ ] Extend existing job runner for DetectDocumentEdges and ApplyPerspectiveCrop payloads `pageId:revision`; retain retry/heartbeat semantics and report final failures against that revision.
- [ ] Enqueue initial edge detection after JPEG/PNG preview creation. Copy the Python script to Worker output and install python3-opencv in Docker; use a local venv for development.

## 3. API and status
- [ ] Add GET crop state, POST detect, POST apply endpoints scoped to an owned document/page. Lock page row, validate expected revision, increment and queue in one transaction.
- [ ] Expose a private crop-source image asset and revision metadata in detail responses. Ready requires matching applied/current revisions; NeedsCrop and Failed remain visible.

## 4. Angular editor
- [ ] Add crop-editor.component.ts with authenticated source loading, an SVG four-point polygon, pointer capture and keyboard movement. Auto detect and Reset update draft points; Apply submits the current revision and polls to completion.
- [ ] Add editor links in document detail, revision-aware preview reload, and clear crop-state messaging.

## 5. Local handoff
- [ ] Compile Worker/API and Angular; apply local migration, restart services, queue eligible existing pages.
- [ ] Manually exercise detection and apply on a local document; inspect saved revisions and new preview. Document any unverified formats or limitations.
